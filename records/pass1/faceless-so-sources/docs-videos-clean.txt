This guide walks the whole lifecycle; publishing and scheduling covers the last stage in depth. Models and cost Pick the model in POST /videos . Credits are charged at creation, not at render: Model Credits What you get storyboard 20 Static AI scenes with motion effects motion_lite 50 Animated transitions between scenes motion_pro 100 Cinematic AI motion video GET /options?kind=models returns the same catalog with costs, so an agent can decide programmatically. 1. Create (POST /videos, scope videos:write) Send a finished narration script and a voice id (from GET /voices ). Optional fields: style , language , name , enableBackgroundMusic , masterStyle , globalNegativePrompt . bash curl -s -X POST https://faceless.so/api/v1/videos \ -H &quot;Authorization: Bearer $FACELESS_API_KEY&quot; \ -H &quot;Content-Type: application/json&quot; \ -H &quot;Idempotency-Key: $(uuidgen)&quot; \ -d &#039;{&quot;script&quot;: &quot;Did you know the ocean has lakes and rivers of its own? ...&quot;, &quot;voiceId&quot;: &quot;EXAVITQu4vr4xnSDxMaL&quot;, &quot;model&quot;: &quot;storyboard&quot;}&#039; Response ( 201 ): json { &quot;success&quot;: true, &quot;data&quot;: { &quot;id&quot;: &quot;665f1b2a9c31a2b3c4d5e801&quot;, &quot;name&quot;: &quot;Did you kn...&quot;, &quot;model&quot;: &quot;storyboard&quot;, &quot;status&quot;: &quot;processing&quot;, &quot;creditsUsed&quot;: 20, &quot;statusUrl&quot;: &quot;/api/v1/videos/665f1b2a9c31a2b3c4d5e801/status&quot; } } Common errors: 402 insufficient_credits (top up before retrying), 403 usage_limit_reached (plan project limit, upgrade to create more), 429 rate_limited (10 creations per 60s per key; wait for Retry-After ). 2. Poll generation (GET /videos/{id}/status, scope videos:read) Generation is asynchronous and typically takes a few minutes. Poll every 10 to 30 seconds until status is completed or failed : bash curl -s https://faceless.so/api/v1/videos/665f1b2a9c31a2b3c4d5e801/status \ -H &quot;Authorization: Bearer $FACELESS_API_KEY&quot; json { &quot;success&quot;: true, &quot;data&quot;: { &quot;id&quot;: &quot;665f1b2a9c31a2b3c4d5e801&quot;, &quot;status&quot;: &quot;processing&quot;, &quot;percentCompleted&quot;: 62, &quot;readyForEditing&quot;: false, &quot;errorMessages&quot;: [], &quot;renderedVideoUrl&quot;: null } } On failed , read errorMessages for the reason. With the CLI, faceless videos create --wait and faceless videos status &lt;id&gt; handle the polling. 3. Render (POST /videos/{id}/render, scope videos:write) Rendering assembles the final MP4 in the cloud. It is free (credits were charged at creation) and requires generation to be completed first. bash curl -s -X POST https://faceless.so/api/v1/videos/665f1b2a9c31a2b3c4d5e801/render \ -H &quot;Authorization: Bearer $FACELESS_API_KEY&quot; \ -H &quot;Content-Type: application/json&quot; \ -d &#039;{&quot;codec&quot;: &quot;h264&quot;}&#039; The 202 response contains a renderId . Poll GET /renders/{renderId} (scope videos:read) every 5 to 15 seconds; renders typically finish in under two minutes: bash curl -s https://faceless.so/api/v1/renders/abcd1234efgh \ -H &quot;Authorization: Bearer $FACELESS_API_KEY&quot; json { &quot;success&quot;: true, &quot;data&quot;: { &quot;renderId&quot;: &quot;abcd1234efgh&quot;, &quot;status&quot;: &quot;done&quot;, &quot;overallProgress&quot;: 1, &quot;url&quot;: &quot;https://exports.faceless.so/renders/665f1b2a9c31a2b3c4d5e801/1722333444555.mp4&quot; } } status is in-progress (with overallProgress 0 to 1), done (with the MP4 url ) or error . The MP4 url is a direct download; it also appears as renderedVideoUrl on the video. 4. Publish Publish immediately with POST /posts , or set per-platform metadata with PATCH /videos/{id} and schedule with POST /posts/schedule . Both are free; see publishing and scheduling . Captioning existing footage (POST /videos/captions) To caption a video or audio file you already have (no AI visuals, no credit cost), send its public URL. Processing is asynchronous; poll GET /videos/{id}/status like any other video. bash curl -s -X POST https://faceless.so/api/v1/videos/captions \ -H &quot;Authorization: Bearer $FACELESS_API_KEY&quot; \ -H &quot;Content-Type: application/json&quot; \ -d &#039;{&quot;videoUrl&quot;: &quot;https://example.com/clip.mp4&quot;, &quot;language&quot;: &quot;English&quot;}&#039; Provide videoUrl or audioUrl (an audio file becomes a captioned video). Rate limit: 10 per 300s. Managing videos GET /videos (scope videos:read): paginated list, newest first, with renderedVideoUrl when available. ?archived=true for archived only. GET /videos/{id} : one video with script, voice, model, status and post metadata. PATCH /videos/{id} (scope videos:write): rename, or set per-platform post metadata before scheduling. DELETE /videos/{id} (scope videos:write): permanent, no credit refund. A 404 not_found on any of these means the id does not exist or belongs to another team.
