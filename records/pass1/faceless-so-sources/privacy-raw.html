When you connect your YouTube account to our Service, we may access the following information through the YouTube API:

We use the information obtained from YouTube API Services to:

YouTube API data is stored securely in our database and is associated with your user account. We implement industry-standard security measures to protect this data, including:

  • Encrypted storage of authentication tokens
  • Secure server infrastructure with access controls

YouTube API data is retained only as long as necessary to provide our Service to you. You can revoke our access to your YouTube data at any time by:
