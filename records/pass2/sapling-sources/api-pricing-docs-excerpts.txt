This page is a Docusaurus tabbed pricing table with one tab per API endpoint (Edits /
Rephrase / Postprocess, Spellcheck, Autocomplete, Semantic Search, Tone, AI Detector,
SDK). The default-visible tab is "Edits / Rephrase / Postprocess" ($0.025 / $0.020 /
$0.015 per 1000 characters by volume tier) -- that rate belongs to Sapling's GRAMMAR
product, a SIBLING of the AI Detector, and must not be used as this product's figure.

tab panel, not a purchase/account action) to read the rate that actually applies to this

though we recommend a minimum length for the text (at least 300 characters) it's
possible to classify the text by sampling portions without evaluating the entire text."
